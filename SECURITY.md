# Security Policy

## Supported versions

Security fixes are provided for the latest release only.

## Reporting a vulnerability

Do not report suspected vulnerabilities in a public issue. Use
[GitHub private vulnerability reporting](https://github.com/Chazutsu/virtual-obsidian/security/advisories/new).

Include the affected version, impact, minimal reproduction steps, and any suggested mitigation.
Use synthetic vault data and remove credentials, personal information, and private note content.

You can expect an initial response within seven days. Disclosure timing will be coordinated after
the report is validated and a fix is available.
